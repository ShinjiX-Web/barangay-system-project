What is an ERD?

An Entity Relationship Diagram (ERD) is a visual blueprint of a database. It shows:

  • Entities — the main objects (tables) in the system
  • Attributes — the properties/columns of each entity
  • Relationships — how entities are connected (one-to-many, etc.)
  • Cardinality — how many instances on each side of a relationship

Relationship Summary
Relationship Type Description
RESIDENTS → CERTIFICATES One-to-Many One resident can request zero or many certificates. Each certificate stores the residentId as a foreign key.
USERS ↔ RESIDENTS Optional One-to-One A user account may optionally be linked to a resident record via linkedResidentId (for residents who have login access).
USERS → ACTIVITY_LOGS One-to-Many Every system action by a user generates an activity log entry referenced by userId. One user can have many log entries.
SETTINGS Standalone Stores barangay-wide configuration (captain name, term dates). No foreign key relationships — it is a single configuration document.
