Q1 View All Residents Simple

Retrieves all registered residents with their key details, sorted alphabetically by last name.

SELECT
    id,
    CONCAT(firstName, ' ', lastName) AS fullName,
    gender,
    birthDate,
    address,
    contactNumber,
    status
FROM residents
ORDER BY lastName ASC;
Q2 View Pending Certificate Requests Simple

Filters certificate requests that are still awaiting processing, ordered by most recent first.

SELECT
    id,
    residentId,
    type        AS certificateType,
    purpose,
    requestDate,
    status
FROM certificates
WHERE status = 'pending'
ORDER BY requestDate DESC;
Q3 Count Residents by Gender Simple

Aggregates the total number of residents grouped by gender for demographic reporting.

SELECT
    gender,
    COUNT(*) AS total
FROM residents
GROUP BY gender;

Q4 Certificate Requests with Resident Names Moderate

Joins certificates with residents to display who requested each certificate, replacing raw foreign keys with readable names.

SELECT
    c.id,
    CONCAT(r.firstName, ' ', r.lastName) AS residentName,
    c.type    AS certificateType,
    c.purpose,
    c.requestDate,
    c.status
FROM certificates c
INNER JOIN residents r ON c.residentId = r.id
ORDER BY c.requestDate DESC;
Q5 Certificate Count by Type with Status Breakdown Moderate

Summarizes how many of each certificate type were requested, with a pivot showing issued, pending, and rejected counts using conditional aggregation.

SELECT
    type                                               AS certificateType,
    COUNT(*)                                           AS totalRequests,
    SUM(CASE WHEN status = 'issued'   THEN 1 ELSE 0 END) AS issued,
    SUM(CASE WHEN status = 'pending'  THEN 1 ELSE 0 END) AS pending,
    SUM(CASE WHEN status = 'rejected' THEN 1 ELSE 0 END) AS rejected
FROM certificates
GROUP BY type
ORDER BY totalRequests DESC;
Q6 System Users with Their Roles Moderate

Lists all staff-level accounts (admin, secretary, staff) sorted by role hierarchy using FIELD() for custom ordering.

SELECT
    id,
    CONCAT(firstName, ' ', lastName) AS fullName,
    email,
    role,
    createdAt
FROM users
WHERE role IN ('admin', 'secretary', 'staff')
ORDER BY FIELD(role, 'admin', 'secretary', 'staff'),
         lastName ASC;
Q7 Residents with Requests in the Last 30 Days Moderate

Finds residents who submitted at least one certificate request within the past 30 days, grouped with their request count and most recent request date.

SELECT
    CONCAT(r.firstName, ' ', r.lastName) AS residentName,
    r.address,
    COUNT(c.id)        AS requestCount,
    MAX(c.requestDate) AS latestRequest
FROM residents r
INNER JOIN certificates c ON r.id = c.residentId
WHERE c.requestDate >= DATE_SUB(CURDATE(), INTERVAL 30 DAY)
GROUP BY r.id, r.firstName, r.lastName, r.address
ORDER BY requestCount DESC;

Q8 Residents Who Never Requested a Certificate Difficult

Uses a LEFT JOIN + IS NULL anti-join pattern to find residents with no certificate records at all, including their computed age.

SELECT
    r.id,
    CONCAT(r.firstName, ' ', r.lastName)        AS fullName,
    r.gender,
    TIMESTAMPDIFF(YEAR, r.birthDate, CURDATE()) AS age,
    r.address,
    r.contactNumber
FROM residents r
LEFT JOIN certificates c ON r.id = c.residentId
WHERE c.id IS NULL
ORDER BY r.lastName ASC;
Q9 Monthly Certificate Issuance by Staff Difficult

Produces a monthly performance report per staff member using a window function (SUM() OVER) to calculate each staff member's share of total certificates issued that month.

SELECT
    CONCAT(u.firstName, ' ', u.lastName)   AS staffName,
    u.role,
    DATE_FORMAT(c.issuedDate, '%Y-%m')     AS monthYear,
    c.type                                 AS certificateType,
    COUNT(c.id)                            AS totalIssued,
    ROUND(
        COUNT(c.id) * 100.0 /
        SUM(COUNT(c.id)) OVER (
            PARTITION BY DATE_FORMAT(c.issuedDate, '%Y-%m')
        ), 2
    )                                      AS pctOfMonth
FROM certificates c
INNER JOIN users u ON c.issuedBy = u.id
WHERE c.status = 'issued'
GROUP BY u.id, u.firstName, u.lastName, u.role,
         DATE_FORMAT(c.issuedDate, '%Y-%m'), c.type
ORDER BY monthYear DESC, totalIssued DESC;
Q10 Full Resident Audit with Activity Ranking Difficult

A comprehensive audit report combining GROUP_CONCAT, conditional aggregation, computed age, and a RANK() window function to rank residents by their total certificate activity.

SELECT
    r.id                                              AS residentId,
    CONCAT(r.firstName, ' ', r.lastName)             AS residentName,
    TIMESTAMPDIFF(YEAR, r.birthDate, CURDATE())      AS age,
    r.gender,
    COUNT(DISTINCT c.id)                             AS totalCertificates,
    SUM(CASE WHEN c.status = 'issued'  THEN 1 ELSE 0 END) AS issuedCount,
    SUM(CASE WHEN c.status = 'pending' THEN 1 ELSE 0 END) AS pendingCount,
    GROUP_CONCAT(
        DISTINCT c.type
        ORDER BY c.type
        SEPARATOR ', '
    )                                                AS typesRequested,
    MAX(c.requestDate)                               AS lastRequestDate,
    RANK() OVER (
        ORDER BY COUNT(DISTINCT c.id) DESC
    )                                                AS rankByActivity
FROM residents r
LEFT JOIN certificates c ON r.id = c.residentId
GROUP BY r.id, r.firstName, r.lastName, r.birthDate, r.gender
HAVING COUNT(DISTINCT c.id) > 0
ORDER BY rankByActivity ASC;
